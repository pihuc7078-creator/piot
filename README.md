Blood Glucose Level Analysis
About the Project
Blood Glucose Level Analysis is a beginner-friendly bioengineering and healthcare data analysis project built with Python. It explores glucose measurements over time and demonstrates how computational methods can organize, analyze, and visualize health-related data.
Objectives
- Load glucose readings from a CSV file.
- Calculate mean, minimum, maximum, and standard deviation.
- Compare readings across meal timings.
- Visualize measurements over time.
- Practice basic data cleaning and interpretation.
Technologies Used
- Python
- Pandas
- Matplotlib
- CSV datasets
Dataset
The included CSV contains synthetic illustrative readings created for practice. They are not real patient measurements or validated reference values. Do not use them to make health decisions.
Limitations
This project is for educational purposes only. It is not a medical diagnostic tool and does not provide treatment recommendations.
